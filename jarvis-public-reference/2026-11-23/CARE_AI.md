# Care AI response review

23 November 2026 · Public project methodology

Read an affirmative answer with the full sentence that identifies what the speaker affirmed. When a material ambiguity remains, ask a focused question. Attribute each reported observation, question and interpretation to its speaker. Reassess when new evidence changes the situation.

For handoffs, date each observation and record which facts still need confirmation. For engineering audits, record the response, its observable consequence and a test for recurrence. Verify a saved revision or external delivery before reporting completion. Use fictional examples in public review material.
